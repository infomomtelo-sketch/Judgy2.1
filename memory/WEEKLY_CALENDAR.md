## CONTENT TEMPLATES

### TikTok Video Template:
```
Duration: 15-30 seconds

0-3 sec: HOOK (text on screen + verbal)
3-10 sec: SHOW the question being typed
10-20 sec: SHOW JudgyGPT response
20-25 sec: REACTION (your face or text)
25-30 sec: CTA ("Link in bio" or "Test me")

Add: Trending sound, captions, hashtags
```

### Instagram Reel Template:
```
Same as TikTok but:
- Add Instagram-specific hashtags
- Use Instagram trending audio
- Add "Share to Stories" CTA
```

### Twitter Thread Template:
```
Tweet 1: Hook + claim
Tweet 2: Problem you solved
Tweet 3: How it works (screenshot)
Tweet 4: Example response
Tweet 5: CTA + link

End each tweet with engagement hook
```

### Reddit Post Template:
```
Title: Descriptive, not clickbait
Body: 
- What you built
- Why you built it
- How it works
- Link (at the end)
- Ask for feedback

Be genuine, not promotional
```
